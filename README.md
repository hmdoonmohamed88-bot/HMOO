# Mohamed Hamed Ahmed CV Site

This folder is ready for GitHub Pages.

## Files
- `index.html`: main portfolio CV page
- `assets/profile.png`: profile image
- `resume-ats.txt`: ATS-friendly plain text resume

## GitHub Pages Deployment
1. Create a new GitHub repository named `mohamed-cv-site`.
2. Upload all files from this folder.
3. Go to repository `Settings > Pages`.
4. Set source to `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. The public link will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/mohamed-cv-site/`
